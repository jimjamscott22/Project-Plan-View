Three Directions for Project Plan Hub

Pick the one that fits how you want to work — or tell me what you'd change.

A

LAN Web App (Recommended)

A small FastAPI backend runs on the same machine as your MariaDB server. All your project data lives in the DB. Every device on your LAN opens http://homeserver:PORT in a browser and sees everything.

  • Import markdown files via drag-and-drop or folder scan from the UI
  • Status changes sync across all devices (no more localStorage)
  • Add/edit projects from any machine
  • Works on Windows & Linux (Python + browser)
  • No per-machine setup after the server is running

Pros

  • Solves everything in one shot
  • Reuses your existing MariaDB
  • Real multi-device sync

Cons

  • Requires a running server process
  • More moving parts than today
B

Improved Static App + Config File

Keep the current file:// approach but make it cross-platform and smarter. A config.json stores one or more folder paths. The Python script reads it so no more hardcoded OneDrive path. A .bat / .sh launcher rebuilds + opens the browser in one click.

  • Multiple scan folders supported
  • Cross-platform paths (Linux / Windows)
  • Optional: push to MariaDB after each build for backup
  • No server needed

Pros

  • Minimal change from today
  • Still works offline / no network

Cons

  • Still need to run the script on each machine
  • No real cross-device sync
  • Status stays in localStorage (per browser)
C

Browser-Native File Import

Rewrite the viewer to use the browser's File System Access API — a folder picker built right into the page. No Python script. Pick a folder, the browser reads and parses the markdown files directly, stores them in IndexedDB.

  • Zero dependencies — just open the HTML file
  • Works on any OS with a modern browser
  • Drag-and-drop individual files also supported
  • Optional: sync to MariaDB via a tiny REST endpoint

Pros

  • No Python required at all
  • Truly cross-platform

Cons

  • IndexedDB is per-browser (not shared across devices without the sync API)
  • File System Access API not available on all browsers
  • Still need the sync endpoint for true multi-device
